# My English Lab

A static, mobile-first English learning app designed to run on free static hosting.

Core features:
- CEFR A1-C2 lessons
- Adaptive local skill scoring and recommendations
- Human recording lookup from open sources when available
- Clearly labelled system-voice fallback
- Click/tap word lookup, Arabic quick meaning, IPA and examples
- Spaced review queue and in-app reminders
- Calendar reminder export for iPhone/system calendar
- Shadowing and browser speech-recognition practice
- Games, XP, streaks, progress, export/import
- PWA install support and offline shell

The app does not claim synthetic voices are human recordings. External open-data services can be unavailable or have incomplete coverage for some words/sentences.
